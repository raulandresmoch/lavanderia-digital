# 🧺 Lavandería Digital

Proyecto de automatización para un servicio de lavandería residencial con recolección y entrega optimizadas.

## 🚀 Funcionalidades

- Registro de pedidos con fechas de recolección y entrega
- Cálculo automático de tiempos según tipo de ropa
- Panel administrativo con pedidos y rutas
- Integración con IA para optimización logística (próximamente)
- Sistema de reservas por calendario
- Pagos en línea (próximamente)
