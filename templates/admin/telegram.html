¿Cómo configurar?
1. Crear Bot de Telegram

  2. Envía /newbot
  3. Sigue las instrucciones
  4. Copia el token
2. Obtener Chat ID
  1. Envía un mensaje a @userinfobot
  2. Copia tu Chat ID
  3. Agrega a tu archivo .env
3. Configurar Variables
